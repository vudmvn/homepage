Các nguyên lý lập trình cơ bản với Python

Fundamental Programming Concepts in Python

Khoa KHDL & TTNT (FDA) — Đại học Kinh tế Quốc dân

Khóa học nền tảng trang bị tư duy giải quyết vấn đề bằng ngôn ngữ Python: Cú pháp, kiểu dữ liệu, cấu trúc rẽ nhánh, vòng lặp, xử lý chuỗi, hàm, đệ quy, lập trình hướng đối tượng (OOP) và xử lý ngoại lệ.

Nội dung trọng tâm:
  • Các kiểu dữ liệu chuẩn, Biểu thức, Điều kiện & Vòng lặp
  • Cấu trúc dữ liệu Python: List, Tuple, Dict, Set & Comprehensions
  • Module, File I/O, OOP Cơ bản & Thực hành thuật toán

Cấu trúc dữ liệu và Giải thuật với Python

Data Structures and Algorithms in Python

Khoa KHDL & TTNT (FDA) — Đại học Kinh tế Quốc dân

Nghiên cứu chuyên sâu về phân tích độ phức tạp thời gian/không gian (Big-O), các cấu trúc dữ liệu tuyến tính và phi tuyến, các thuật toán sắp xếp, tìm kiếm và kỹ thuật thiết kế thuật toán cốt lõi.

Nội dung trọng tâm:
  • Phân tích tiệm cận (Big-O, Big-Omega, Big-Theta)
  • Sắp xếp nâng cao: MergeSort, QuickSort, HeapSort
  • Danh sách liên kết, Ngăn xếp, Hàng đợi, Cây & Bảng băm

DSAI1005 3 Tín chỉ

Phân tích dữ liệu với Python

Data Analysis with Python

Khoa KHDL & TTNT (FDA) — Đại học Kinh tế Quốc dân

Quy trình khai phá và phân tích dữ liệu thực chiến với hệ sinh thái Python: Xử lý mảng đa chiều NumPy, thao tác bảng dữ liệu lớn với Pandas, làm sạch dữ liệu, phân tích khám phá (EDA) và trực quan hóa chuyên nghiệp.

Nội dung trọng tâm:
  • NumPy Vectorization, Broadcasting & Ma trận
  • Pandas Series, DataFrame, GroupBy, Pivot & Merging
  • Trực quan hóa với Matplotlib & Seaborn, Dự án phân tích thực tế

Hệ quản trị cơ sở dữ liệu và MySQL

Database Systems: Design, Implementation & Management

Khoa KHDL & TTNT (FDA) — Đại học Kinh tế Quốc dân

Tài liệu học tập toàn diện về hệ quản trị CSDL: Kiến trúc dữ liệu đa tầng, mô hình thực thể liên kết (ER/EER), ánh xạ sang lược đồ quan hệ, chuẩn hóa quan hệ (1NF–BCNF), thực hành ngôn ngữ SQL & tối ưu hóa chỉ mục với MySQL.

Nội dung trọng tâm:
  • Kiến trúc DBMS, Độc lập dữ liệu & Mô hình quan hệ
  • Thiết kế ERD, Functional Dependencies & Chuẩn hóa dữ liệu
  • Lập trình MySQL: DDL, DML, Truy vấn SELECT, Transactions & Index

VNU1001 Tương tác số

Nhập môn công nghệ số & ứng dụng AI

Introduction to Digital Technology & AI Applications

Đại học Quốc gia Hà Nội (VNU)

Cổng học liệu số thông minh cho sinh viên: Tổng quan về chuyển đổi số, nền tảng AI hiện đại (GenAI, LLM), tích hợp bài giảng tương tác HTML, hệ thống Quiz tự chấm điểm, sổ tay đề cương và thời khóa biểu 17 mốc học tập.

Nội dung trọng tâm:
  • Bài giảng tương tác & Quiz trắc nghiệm tự chấm trực tuyến
  • Sổ tay đề cương chi tiết & Thời khóa biểu 17 mốc LMS/Zoom
  • Cẩm nang hướng dẫn xử lý lỗi kỹ thuật thường gặp

CP 57 Chuyên đề

Cẩm nang Huấn luyện Lập trình Thi đấu (ICPC & OLP)

Competitive Programming Handbook & Problemsets

SLSCM Lab — Khoa KHDL & TTNT (FDA), NEU

Kho tài liệu huấn luyện thuật toán đỉnh cao cho đội tuyển ICPC & Olympic Tin học sinh viên: 57 chuyên đề phân cấp Star Levels, cấu trúc Bộ 3 Tác chiến (Lý thuyết, Template C++20 tối ưu, Bài tập chọn lọc), thư viện 107+ file PDF vector và bộ đề thi OLP kèm lời giải chi tiết.

Nội dung trọng tâm:
  • 30 Chuyên đề One-star: Số học, Bitmask, Hai con trỏ, BFS/DFS, QHĐ cơ bản
  • 27 Chuyên đề Two-star: Segment Tree, Fenwick, DSU on Tree, SOS DP, Mo's
  • Thư viện 107+ PDF Vector in ấn & Bộ đề thi OLP có lời giải
